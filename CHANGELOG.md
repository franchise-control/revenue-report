# Изменения

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
версии — [семантические](https://semver.org/lang/ru/).

## [1.0.0] — 2026-09-27

Первый выпуск.

### Добавлено

- Разбор денежной суммы из того вида, в котором её присылают: неразрывные
  пробелы из 1С, запятая и точка как разделитель копеек, разряды, обозначения
  валюты, бухгалтерские скобки вместо минуса. Неоднозначная запись отвергается,
  а не угадывается.
- Отчётный период как полуинтервал: календарный месяц, диапазон «с … по …»
  включительно, разбор «2026-09», «09.2026», «сентябрь 2026» и диапазонов.
  Проверка существования дня, високосные годы, подпись для акта.
- Проверка отчёта со списком всех ошибок сразу, с путём к каждому полю.
  Обязательные показатели по форме сети, русские имена полей.
- Разбор CSV по RFC 4180: BOM, определение разделителя, кавычки, переводы
  строки внутри поля, номера строк в ошибках.
- `toVariables` — стыковка с royalty-calc одной строкой.
